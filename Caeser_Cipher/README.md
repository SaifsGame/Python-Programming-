# 🔐 Caesar Cipher 

A Python implementation of the classic Caesar Cipher. This project demonstrates foundational cryptography concepts by encrypting and decrypting text using a simple shift substitution mechanism. It serves as an excellent practical exercise for understanding data obfuscation and basic cybersecurity principles.

## 🚀 Features
- **Encrypt Messages:** Secure plain text by shifting characters down the alphabet.
- **Decrypt Messages:** Retrieve the original text using the reverse shift key.
- **Customizable Shift Key:** Choose any integer value to determine the cipher's complexity.
