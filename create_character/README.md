# 🧙‍♂️ Create Character

A Python-based character generation tool. This project demonstrates core programming concepts such as user input handling, data structuring, and logical flow. It is designed to create character profiles via the command line, making it a great practical exercise in Python development.

## 🚀 Features
- **Dynamic Generation:** Create unique character profiles based on specific attributes.
- **Interactive Prompts:** A clean command-line interface that guides the user through the creation process.
- **Data Handling:** Showcases how to store, format, and display user-generated data effectively.
